Trained Isolation Forest & Reconstruction Autoencoder on time-series telemetry (CPU, RAM, latency, socket count) detecting anomalies before service outages.

2. Vector RAG

Vector database indexing enterprise SRE runbooks, post-mortem incident logs, and architectural mitigation procedures with semantic top-k retrieval.

3. AI Multi-Agents

LangGraph state machine coordinating Telemetry Monitor Agent, Incident Investigator Agent, and Remediation Agent.

4. LLM Synthesis

Produces executive plain-English Root Cause Analysis (RCA) briefs, blast-radius estimations, and long-term remediation recommendations.
