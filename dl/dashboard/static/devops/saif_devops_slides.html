Multi-Tier Observability Model

Tier 1: ALB Ingress

Synthetic uptime testing on public ALB endpoint verifying SSL, latency, and HTTP 200 response codes.

Tier 2: NRPE Probes (Port 5666)

Deep internal inspection of private nodes: memory usage (check_mem), disk space (check_disk), and load average.

Tier 3: Network ICMP

VPC internal ping latency and packet loss verification to confirm network path integrity.
