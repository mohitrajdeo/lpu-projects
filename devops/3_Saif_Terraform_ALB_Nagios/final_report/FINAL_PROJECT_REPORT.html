📋 Executive Summary & Abstract

This project presents an enterprise-grade high-availability infrastructure architecture designed by Saif Siddique for INT333. The solution employs HashiCorp Terraform to deploy a Multi-Tier Application Load Balancer (ALB) across multiple AWS Availability Zones (ap-south-1a and ap-south-1b), balancing traffic across redundant worker instances running the SecOps Cyber Threat Hunter microservice. Nagios Core monitors cluster health; when node failure occurs, the ALB automatically executes connection draining and redirects traffic to surviving nodes with zero dropped requests.

🏗️ System Architecture & Engineering Design

The architecture comprises public subnets hosting the Application Load Balancer, private subnets hosting worker nodes (Node 1 Primary and Node 2 Secondary), and a management subnet hosting Nagios Core. Target group health checks poll `/health` every 10 seconds.
