📋 Executive Summary & Abstract

This project presents an enterprise-grade Infrastructure as Code (IaC) and observability architecture designed by Mohit Raj Deo for INT333. The solution employs HashiCorp Terraform to provision a secure, multi-tier AWS cloud topology comprising custom VPCs, public and private subnet segregations, internet gateways, and security groups. The infrastructure deploys a containerized multi-tier application stack consisting of an Nginx reverse proxy ingress, the Autonomous AIOps Neural Telemetry microservice (Port 5001), an isolated Python backend code-execution daemon (Port 9010), and a dedicated Nagios Core 4.5 continuous monitoring engine.

🏗️ System Architecture & Engineering Design

The architecture implements two distinct network tiers: Tier 1 (Public DMZ) hosts the Nginx reverse proxy and AIOps microservice; Tier 2 (Internal Isolation) hosts the backend code-runner daemon accessible only via Tier 1 security group ingress. Nagios Core 4.5 continuously monitors all sockets and services.
