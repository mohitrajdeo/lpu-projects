Declarative Puppet Modules

nginx_server

Installs Nginx, pushes ERB virtual host configuration templates, and ensures the service is running and enabled.

ssh_hardening

Enforces enterprise security baselines: disables root login via SSH and mandates public-key authentication.

nrpe_monitoring

Deploys Nagios Remote Plugin Executor (NRPE), whitelists Nagios Server IP, and exposes deep OS metrics.
