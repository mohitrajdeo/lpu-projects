📋 Executive Summary & Abstract

This project implements an automated, declarative configuration management and observability platform designed by Akash Choudhary for INT333. The system pairs Puppet Master/Agent desired-state enforcement with Nagios Core and Nagios Remote Plugin Executor (NRPE) continuous monitoring. Modular Puppet manifests (`nginx_server`, `ssh_hardening`, `nrpe_monitoring`) manage target hosts running the Autonomous SWE Platform. When manual configuration drift or service failure is introduced out-of-band, Nagios NRPE flags a CRITICAL alert, and Puppet automatically triggers a catalog run to remediate the node back to GREEN OK.

🏗️ System Architecture & Engineering Design

The declarative Puppet catalog enforces package installation, configuration file templating, service daemons, and SSH security hardening. Nagios NRPE executes check_nrpe probes over TCP 5666; any state violation triggers automated remediation.
